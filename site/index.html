DataPipe testbed

Test experiments for DataPipe, for checking a deployment end to end: one written with jsPsych and @jspsych/extension-pipe, one in plain JavaScript using datapipe-client. Both stage each trial as it happens. They send real data to a real DataPipe experiment, so point them at a test deployment and a test experiment.

What to check

Create an experiment on the deployment you are testing (for the test site, sign in at datapipe-test.web.app), switch data collection on, and keep its dashboard open in another window while you run these.

Run them in this order. Switching data collection off for the last one while an earlier session is still staged destroys that session’s recovery — the sweep discards staged trials for an experiment that is no longer accepting data.
